# YAKBD Editor @VERSION@

A preview of the desktop editor for `.kbl.json` keyboard layouts, with the yakbd command-line tool
@CLI_VERSION@ inside. What changed: [What's new](https://yakbd.github.io/releases).

- **Windows:** [`yakbd-gui-setup.exe`](https://github.com/yakbd/yakbd-gui/releases/latest/download/yakbd-gui-setup.exe) (editor and CLI; x64 and ARM64)
- **macOS:** `YAKBD-Editor-@VERSION@.dmg` (Apple silicon and Intel; not notarized: allow it once in Privacy & Security)
- **Linux:** `YAKBD-Editor-@VERSION@-x86_64.AppImage` (x86-64, glibc 2.35 or later)

Install guide: [yakbd.github.io/guide](https://yakbd.github.io/guide/#the-editor). Check a download with `SHA256SUMS` or
`gh attestation verify <file> -R yakbd/yakbd-gui`. Licences (Qt under the LGPL v3) and the AppImage runtime sources:
[NOTICE](https://github.com/yakbd/yakbd-gui/blob/main/NOTICE).
